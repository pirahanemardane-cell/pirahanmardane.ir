# User Flows — خریدار / فروشنده / ادمین

## خریدار
1. ورود/ثبت‌نام OTP یا رمز
2. مرور PLP → PDP → سبد
3. ثبت سفارش → پرداخت (mock یا واقعی)
4. پیگیری وضعیت / مرجوعی / تیکت

## فروشنده
1. ثبت‌نام/KYC سطح پنل
2. افزودن محصول + تصویر
3. دریافت سفارش جدید → تأیید → ارسال + tracking
4. تسویه / تغییر شبا
5. دانلود CSV حسابداری

## ادمین
1. ورود با نقش admin
2. مدیریت sellers (از جمله archive)
3. سفارش‌ها و تیکت‌ها
4. بررسی critical/errors

## لبه‌های UX برای رگرسیون دستی
- تغییر تب فروشنده بدون پرش URL اشتباه
- breadcrumb تکراری نباشد
- آرشیو فروشنده از لیست عمومی خارج شود
- موبایل هدر و منو
