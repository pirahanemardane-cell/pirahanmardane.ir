# Realtime سراسری

## پوشش
- products → فروشگاه، PLP، اسلایدر، پنل‌ها
- orders → خریدار / فروشنده / ادمین
- sellers → لیست و پنل ادمین
- notifications → اعلان‌ها
- tickets → پشتیبانی (اگر جدول باشد)

## SQL
یک‌بار `sql/realtime-publication.sql` را در Supabase SQL Editor اجرا کن.

## محدودیت
کاربر آفلاین تا اتصال بعدی به‌روز نمی‌شود.
