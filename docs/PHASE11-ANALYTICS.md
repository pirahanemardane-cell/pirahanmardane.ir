# فاز ۱۱ — آنالیتیکس قیف

رویدادهای ثبت‌شده از طریق trackGa4Event (local + gtag/dataLayer اگر فعال باشد):

- view_item — باز کردن صفحه محصول
- add_to_cart — افزودن به سبد
- search — جستجو
- begin_checkout — شروع تسویه

در پنل ادمین تب آنالیتیکس این رویدادها قابل مشاهده‌اند (ذخیره محلی).
اگر GA/GTM در تنظیمات سئو فعال باشد، به dataLayer هم push می‌شوند.
