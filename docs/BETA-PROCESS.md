# Beta کنترل‌شده — فرآیند formal

## هدف
۱۰–۳۰ کاربر واقعی قبل از اعلام عمومی (مستقل از SMS/درگاه نهایی).

## مراحل
1. لیست دعوت (شماره/ایمیل) در شیت یا تیکت ادمین
2. کانال فیدبک: تیکت داخل سایت یا فرم ساده
3. برچسب شدت: P0 (مسدودکننده خرید/ورود) / P1 / P2
4. هر P0 قبل از دعوت موج بعد بسته شود

## معیار پایان بتا
- هیچ P0 باز از موج آخر
- حداقل یک خرید آزمایشی end-to-end در حالتی که سیاست محصول اجازه می‌دهد
